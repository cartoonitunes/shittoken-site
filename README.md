# shittoken-site

Static site for **ShitToken** (`0x337Bc91CA04FD03a1eDA22bCe71550C0d928B037`) — the first of the two ShitToken contracts deployed July 23, 2017 by `0xc952b2016f059483b8e365f3e53636ef0fe6fe6d`. Source recovered from raw bytecode.

## Layout

- `index.html` — current site
- `preview.png` — rendered preview
- `legacy/` — the 2017 site as forked from [shitcoingod/shittoken](https://github.com/shitcoingod/shittoken), preserved verbatim. The original `index.html` there points at the *second* deployment (`0xdbd98373c5152963ae9940e0477f078bd28ac411`), which is the one announced on BitcoinTalk.

This site is intended for IPFS pinning + ENS contenthash.
